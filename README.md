# マンション管理士 オリジナル問題集

マンション管理士試験の形式（50問・四肢択一）を再現した、非公式の学習用サイトです。
問題はすべてオリジナルで、直近の法改正・判例を中心に出題し、本試験よりかなり難しめに作っています。全肢の正誤解説と根拠条文付きです。

- 第1回〜第3回：本編50問ずつ（公式の出題範囲4分野に準拠した配分）
- 頻出問題コーナー：頻出論点に絞った50問
- 練習モード：1問ごとに即時採点と詳しい解説。続きから再開でき、分野別の進捗が分かります。
- 模試モード：120分のタイマー付きで50問を通しで解き、最後に採点と全問レビューを表示します。
- 学習記録はブラウザの localStorage にのみ保存されます（サーバー送信なし）。
